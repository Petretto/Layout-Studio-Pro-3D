# Release
Define release/pilot scope first. Do not imply full CAD/simulation replacement or industrial certification beyond documented scope.

Group expensive checks: clean build/package; target-environment startup; save/backup/restore; update and project compatibility; dependencies/licenses; 3D asset licenses/source metadata; browser/computer/offline requirements; agreed acceptance scenarios; known limitations; user docs/screenshots/changelog.

Separate measured data from assumptions. Do not claim accuracy outside verified scenarios/tolerances. Do not present geometric warnings as BHP certification. Do not double-count modeled losses and OEE reserve.

Release readiness requires recorded evidence for installation/update/recovery, acceptance, documentation and limitations.
