# Layout Studio Pro 3D

Aplikacja React/TypeScript/Three.js do projektowania i symulacji linii produkcyjnych.

- [Plan rozwoju i bieżący pakiet](PLAN_ROZWOJU.md)
- [Indeks dokumentacji](docs/README.md)
- [Instrukcja użytkownika](Instrukcja/Podrecznik_Uzytkownika.md)
- [Zasady pracy w repozytorium](AGENTS.md)

Instalacja: `npm install`. Praca lokalna: `npm run dev`. Wydanie: `npm run build`.

Nowe modele domenowe, raporty i notatki zapisuj w odpowiednim podkatalogu `docs/`, zamiast w katalogu głównym. Materiały projektowe Pencil przechowuj w `design/`, a dowody testów w `outputs/qa/`.
